Library Front Office Manager — Microsoft Access starter kit

Files:
- Library_Front_Office_Schema.sql: Access SQL table definitions (run one CREATE TABLE statement at a time in Access SQL View; see setup guide).
- Access_VBA_Code.txt: VBA code for digital signature capture and attendance/loan workflow helpers.
- Access_Setup_Guide.docx: step-by-step setup instructions and form/report design.
- Sample_Data.csv: optional sample schools/items to import; contains no real student data.

Important: This kit is a buildable starter package, not a compiled .accdb file. Microsoft Access must be installed to create and run the database. Access SQL syntax varies by version; create tables in the order shown and add relationships in Database Tools > Relationships. Test with fictional data before live use.
